My Bookmarks PWA v1.0.0

將此資料夾內所有檔案上傳至 GitHub Pages 同一目錄，保留檔名。
使用 HTTPS 網址開啟，不能透過雙擊本機 HTML 安裝 PWA。

iPhone / iPad：Safari 開啟網址 → 分享 → 加入主畫面 → 如有「以網頁 App 開啟」請開啟 → 加入。
Android：Chrome 開啟網址 → 選單 → 安裝應用程式／加到主畫面。
電腦：Chrome 或 Edge 使用網址列安裝圖示；Mac Safari 可使用加入 Dock。

首頁首次成功載入並完成快取後可離線開啟。書籤連結的外部網站仍需要網絡。
14 個書籤及 6 個內嵌網站圖示均保留。
更新版本時請同步修改 sw.js 的 CACHE 版本，關閉並重新開啟 App 以使用更新。
